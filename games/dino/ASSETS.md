# Assets (private repo only)
This folder includes third-party copyrighted material from the shareware demo of "Dino and Aliens" (NevoSoft, 2004): `public/assets/` (what the web build loads), `original/dino_demo/` (original exe/data), `extracted/` (raw extraction output). Keep this repo PRIVATE; do not make it public or redistribute.
Run: `cd games/dino && npm install && npm run dev` (or `npm run build` → `dist/`, see DEPLOY.md).
