# Dino and Aliens (NevoSoft 2004) - reverse engineered formats

Source: DinoAndAliens.exe (Ghidra 12.2 decompile, 2201 functions). Local, non-commercial use only.

## Containers (*.dat)
Sequence of entries: `name\0` + `uint32 size` + `size` bytes. Body is XOR-ed with `name` repeated.
Unpacker: scratchpad `unpack.py`; output in `/Users/congpham/Desktop/game/dino_assets/<dat>/`.
Sounds are plain .ogg, textures plain JPEG after unpack.

## .cgo  (text INI, CRLF) object description
`[meshes] nummeshes=N meshK=file.msh textureK=file.jpg` `[bounds] numbounds=N boundK.name= .b_circle= .center.x/y/z= .radius= | .dx= .dy=`

## .msh  static mesh  (loader FUN_0042bdc0)
```
0   "MSH" + u8 flag(1)
4   vec3 position   (node transform, mostly 0)
16  vec3 rotation   (euler)
28  u8   unknown(1)
29  u32  V  vertex count
33  u32  T  triangle count
37  V * vec3 positions
    T * 3 * i32 indices
    T * 3 * (u,v) f32   UV per triangle corner; engine uses v = 1 - v
```
Size check: 37 + 12V + 12T + 24T. Normals: flat per-face (engine computes).

## .skl  skinned character  (loader FUN_00432840)
```
u32 NV  (vertices)   u32 NB (bones)
NB  * vec3           bone local offsets/positions            (-> +0x28)
NV  * 60 bytes       3 influences * { f32 weight; i32 bone; vec3 offset }  (weight == 0 -> unused)  (-> +0x30)
NB  * 56 bytes       bone record: i32 nChildren, i32 children[...]         (-> +0x2c)
u32 NT
NT  * 3 * i32        indices
NT  * 3 * (u,v)      UV per corner, v = 1 - v
```
Check bugai.skl: 8+39*12+476*60+39*56+4+944*36 = 65208.
Skinning (FUN_00401a80): v = sum_i w_i * (M[bone_i] * offset_i)   (to verify), M = bone world matrix from FUN_00401830 (recursive over children).

## .anm  animation  (loader FUN_00403de0)
```
u32 B (bones)  u32 msPerFrame (33)  u32 F (frames)
F * vec3                   root translation per frame
B * F * vec3               euler angles per bone per frame, index [bone*F + frame]
```
Check beg.anm: 12 + 12*24 + 12*46*24 = 13548. Euler -> quaternion (FUN_00404170, 3 axis quats multiplied; divisor DAT_0048c320).
Interpolation between frames: linear/slerp with fraction.

## .chr  64 bytes: `char skl[32]; char texture[32]`  (FUN_004013c0)
Special bones by name: "Bip01 Spine1" (upper/lower body split), "Bip01 L Thigh", "L Eye", "R Eye".

## .lev  text: name=, numpack, difficulty, music, numbombs, numgrenades, numradiobombs, sun=(x,y,z), map= then ASCII grid (51 cols x ~50 rows)
Tile legend: see FUN_00407890 (level loader) in decompile.

## Other
.rec = demo replay (not needed). texts: menu.txt, menutext.txt, tips.txt (INI-ish).

## World / level legend (from FUN_00407890, FUN_00407430, FUN_00406f40)
Grid is square N x N (N = width of first map row; rows end CRLF). Cell = 5.0 world units; world = cell*5 - N*5/2 (N*5/2 = DAT_004a4eb8). Object placed at footprint (w x h cells) from FUN_00406f40(char,w,h,x,y,rotDeg,cgo,...). Angle consts: DAT_0048c3dc=90, DAT_0048c310=57.2958 (rad->deg), 0x42b40000=90, 0x43340000=180, 0x43870000=270.
Chars (ASCII): `.` empty; `$` kust01; `%` metalbox 2x2; `&` oduvanN(1-3); `*` paporotnikN(1-3); `0` stone02; `1-9` tablo (tip); `<>^v` strelka rot (>:90 <:180 ^:? v:?); `@` penekN(1-4); `B` buket; `E` exit 4x4; `F` flower; `G` grass1; `I` paling0N fence (post paling_stolb at junctions); `L` lazer 2x2, dir by next-right char (> =1,^=0,<=3,v=2)*90, '+' below = on/off, digit below-right = id; `M` enemy spawn: char below = type 1 vilka,2 sniper,3 dlinnyi,4 bugai (default 1), char right = facing v=2,<=4,^=6 else 0 (x45deg); `O` stone01; `P` palm1; `Q q w` water (bottomN); `T` treeN; `W` kirpich brick wall (bashnya at corners); `g` vorota gate; `k` key; `o` stone03; `p` palm2; `r` reshetka; `t` treeNdry; `z` zamok (lock, 4x1 or 1x4); `|` zabor0N fence (random 1-4); `#` box.cgo 2x2 (pushable box); `+` flag for laser.
Cp1251 high bytes: 0xC1 bochka.cgo 2x2 (barrel); 0xC3 hero start (2x2 area?); 0xC7 mirror.cgo 2x2; 0xE0 bonus_ananas; 0xE1 batareyka; 0xED bonus_nevidimka; 0xEF/F0/F1 bomb2; 0xF7 bonus_clock; 0xFD bonus_life025; 0xFE bonus_life05; 0xFF bonus_life. Other high chars (0xCE,0xC5,0xC0,0xC8..) not yet resolved (likely remaining switch cases / enemy markers).
Enemy chr: vilka.chr, sniper.chr, dlinnyi.chr, bugai.chr. Anim frame period 33 ms.

## Hero animation / input facts (verified in decompile, FUN_0041fb70 / FUN_00422fc0 / FUN_00421640 / FUN_004237f0)
Hero states: 0 stand, 1 run=**beg.anm** (walk.anm is loaded but unused by the hero), 4 death (random of death/death2), 5 kick=pinok.anm (hit lands when remaining timer is in [0.4*len, 0.4*len+33ms), i.e. at 60% ELAPSED, not 40%; range < 14.15; vtable call with power 10 on the object in front, flag 0x10), 7 push=tolkanie, 8 exit=mahanie.anm + teleport.ogg.
Idle: after 2 plain stand cycles (each replays stand for exactly its anm length F*ms/speed, not random), each cycle picks rand(6) of [stand, zaryadka, zaryadka2, chihanie, zevota, glavnyi_pause_time]; zaryadka2 -> zaryadka when blocked ahead; chihanie.ogg plays at 68% (sound not in demo).
Dance (key flag 0x80): dance1/dance2 (dance2 with prob 2/3 unless blocked), ends after anim - 300 ms; poklon.anm is loaded but never used; history/glavnyi_sintezator are INFO-screen only.
Hero movement (verified, FUN_00420030 / FUN_00421ba0 / FUN_00402390 / FUN_00402540 / FUN_00406b70): logic tick fixed 33 ms (timeSetEvent 0x21, FUN_0043a4e0). Run: vel = unitDirVec[dir]*1.0*speed(+0x278; 1.5 after clock) per tick, so 1 unit/tick = 30.3 units/s (cell = 5 units; diagonals unit length, 0.7071/axis). 8 dirs: R=0 RD=1 D=2 LD=3 L=4 LU=5 U=6 UR=7. Turn = linear over 200 ms/speed regardless of angle, shortest path (|diff|>180 -> +-360). Hero footprint = 2x2 cells, free test FUN_0040b150 (cell flag 0x12). Cell change decided one tick before block centre (ceil if vec<0 else floor). Blocked diagonal: slide along free orthogonal neighbour at 0.9*speed (slide flag +0x384); axis blocked: stop; both front cells flag 0x800 -> state 7 push. Dance timer = F*ms-300; kick starts only if all 4 front cells lack flag 2. Footstep timer +33/tick, wraps >380/speed (stephero1..3.ogg).
Web port status: superseded - the grid block-centre scheme, slide 0.9, turn 200 ms and anm blend are ported (see "Hero grid model" and "Flag grid, push, exit, destroy" below); the web Character.play has the exe 200/50/100 ms blend.

Default keys (DirectInput table FUN_0043f600): LCtrl FIRE(set bomb), LShift NEXT WEAPON, Space USE/KICK, arrows move, Q/W/E fast bomb 1/2/3, D dance, PgUp/PgDn zoom. Radio bomb: press FIRE again to detonate (tips.txt).
Enemy states (FUN_0040edc0): 0 pause, 1 run, 2 attack, 3 perekrest (fidget), 4 dead (1 s), 6 shock. Idle end: 1/4 chance then 50/50 perekrest.

## Rendering facts (verified in decompile / assets)
- .msh vertices are **Z-up** (height along z, base at z=0): engine swaps y/z (loadCgo uses (x, z, y)). Node pos/rot in header are ~0 for all checked meshes.
- Fences/walls (FUN_00407890): pre-pass puts posts (paling_stolb / kirpich_bashnya, rot 180) at junctions (and next to g/z gates for 'I'; brick corners/ends/isolated). Main pass: horizontal runs `palingN.cgo`(N=1..2)/`zaborN.cgo`(1..4)/`kirpich_base_opt.cgo` rot 180; vertical runs `*_bok.cgo` rot -90 (brick: `kirpich_base.cgo` rot 90). A cell already occupied is skipped.
- Water 'w','q','Q': per-cell `bottom0..3[a].cgo` chosen by 4-neighbour water mask (0 bed, 1 two-side corner, 2 edge, 3 inner corner) with rot 0/90/180/270; ground has holes under water. Water surface: see CAMERA/RENDER STATES entry.
- CAMERA/PROJECTION/RENDER STATES (CONFIRMED from DinoAndAliens.exe):
  - Projection FUN_0043a400 -> FUN_0043ad10 (D3DXMatrixPerspectiveFovLH): vertical fov PI/4 (45 deg), aspect clientW/clientH (recomputed on WM_SIZE), near 1.0, far 1500. UI = ortho 800x600 (FUN_0043bd00).
  - Camera FUN_004158e0 (every frame, dt = real ms, k = min(1, 0.01*dt)): C = lerp(C, hero 0x4dcfe8, k); clamp game x to +-(half-80), game y to [-(half-75), half-40] (half = N*5/2), z free. View: rotate identity about X by pitch = -138 + 6*zoom deg (FUN_00406580), eye = C - fwd*(D-15*zoom) - up*4.46 with D=77.5 (FUN_004154d0), fwd = col2, up = col1. Zoom in [0,1]: vel += wheel*0.002, +0.2 per frame if PgUp, -0.2 if PgDn; zoom += vel*k; vel *= (1-k). At zoom 0 eye = hero + (0, 55.17, 54.6)_game z-up; pitch -138 deg (~42 deg looking down).
  - Engine world is Z-up LEFT-handed; three = (x_g, z_g, y_g) swap gives right-handed (the image is not mirrored, but triangle winding flips: loadCgo/character.js swap corners 1<->2, see last section); screen right = +x, screen up on ground = -y_game. Cull mode CCW (state 3).
  - Render states FUN_0043b7d0: ZENABLE 1, alpha test ref 0x80 GREATEREQUAL, LIGHTING 0 by default, global AMBIENT white, tex stage0 WRAP u/v, MAG/MIN/MIP LINEAR, ALPHAOP MODULATE. No fog (state 0x1c never set). Gameplay frame has no colour clear (only Z clear FUN_0043a670); other clears black -> background black.
  - Light FUN_00407890/FUN_00414330: type directional, dir = normalize(sun)(x,y,-z) (sun z always -1 in .lev), diffuse (1,1,1), light ambient 0; default material 0x4dd128 diffuse 1 ambient 0.2 (global ambient white).
  - Water FUN_004393f0 (+FUN_00438d80, FUN_00438f70, FUN_00439740, FUN_004390e0): objects type 0x77; blend SRCALPHA/INVSRCALPHA, lighting off, zwrite off. Frame = floor(t_ms/65) % 22 over water01..22.jpg. Flat quad 5x5 at objpos-(2.5,2.5,2.3), vertex alpha 0x78, UV span 0.5 offset (gx&1,gy&1)*0.5. Wave mesh (water.jpg, alpha 0x5a, 4x4 verts, 3x3 quads, same origin): z = 0.4*sin(t*0.005+ix*2pi/3)*cos(t*0.005+iy*2pi/3), uv scroll (0.0002,0.0001)*t_ms. Texture filter LINEAR.
  - GUESS/unconfirmed: camera initial C (exe BSS 0, web snaps to hero), death/exit cutscene camera (timers 7000/14000 ms, FUN_004155b0 wander), obj z of water = 0, wave mesh parity field +0x1f0, flat-quad UV orientation, mouse-wheel units, aspect vs 4:3 previews.
- stone01/02/03.cgo also reference `travka_*.msh` (texture lazer_screen.jpg): drawn like every other mesh, NOT hidden (CONFIRMED, see last section and "Level loader").
- parseLev pads short rows/columns with '.' (p02_l08 is 63x60).
- Characters (.skl/.anm) CONFIRMED (FUN_00404170, FUN_004042b0 x87-emulated, FUN_00402cd0, FUN_00401600, FUN_00401830, FUN_00401a80, FUN_00402df0):
  - Euler (radians) -> quaternion q = qz*qy*qx (three.js order 'ZYX', NOT 'XYZ'). Quaternion -> D3D row matrix = standard R(q).
  - Skeleton is Z-up, forward = +X, feet at z=0 (no ground lift needed). Mapped to three as (x,y,z)->(x,z,y) like loadCgo (reflection: triangle winding flipped).

  - Enemy initial facing (face*45deg) sign and direction table DAT_005706f8 initializer: UNCONFIRMED (GUESS).
- Characters use smooth (welded) vertex normals; flat shading made enemies look broken vs previews.

## Hero grid model (ported in src/main.js heroTick / stepHero)

- Cell record (x,y) at 0x4b6ae8 + x*0x400 + y*8: +0 id0 (static obj, flag 4), +2 id1 (movable, flag 0x80), +6 u16 flags.
- Loader flags (FUN_00407890 / FUN_00406f40): default 0x1803; '$','T','t' = 3; '&','*','B','F','G','E' = 0; '0','O' = 0x1003; '1'-'9' = 0x5803; 'L' = 0x5003; water 'Q','q','w','r','|' = 2; 'W' = 0x9803; 'z' = 0x5803; pickups = 0x200; '#' boxes 0x1883; exit 'E' 4x4 flag 4, corners |= 3; map border |= 3.
