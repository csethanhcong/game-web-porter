Installation
------------

Important! 
The latest version of "Tank-o-Box" is always available for downloading
from the web page at:

   http://www.myplaycity.com

To install "Tank-o-Box", just copy the distribution kit content into the 
temporary directory, run the "tankobox_setup.exe" and follow the
instructions.


Uninstallation
--------------

To uninstall "Tank-o-Box" from your computer, open 
the Control Panel and double-click on "Add/Remove Programs" 
applet. Then select "Tank-o-Box" from the list and click 
the Add/Remove button. Follow the instructions that appear 
on the screen.
